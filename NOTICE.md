# NOTICE / Provenance

Tuya Zigbee Lock Local (TZLL) originated from:

**Door-Lock-TY0A01-with-TYZS3-to-Z2M-firmware**  
https://github.com/nickieftekhari-dotcom/Door-Lock-TY0A01-with-TYZS3-to-Z2M-firmware

Original author / repository owner:

**Nicki Eftekhari / nickieftekhari-dotcom**

TZLL preserves the upstream Git history and continues to contain upstream-derived implementation and documentation.

TZLL modifications and later development include, among other work:

- TYZS5 target support in addition to TYZS3;
- shared common-core architecture;
- Product Binding and Capability Profile separation;
- Control / Monitor Access Editions;
- independent read-only Monitor firmware/converters;
- hardened Zigbee2MQTT converters and credential-list decoding;
- Home Assistant integration guidance;
- expanded tests, release auditing, compatibility tracking and repository CI/security governance.

A detailed technical relationship is documented in:

`docs/UPSTREAM_AND_PROVENANCE.md`
